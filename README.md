# Voice Assistant

A voice-first personal operations assistant for reminders, notes, tasks, conversational planning, music, travel, weather, search, and quick actions.

## Live Demo

[Open the Voice Command Center](https://voice-command-center-iota.vercel.app/)

## Highlights

- Voice and typed commands
- Conversational follow-up responses
- Reminder and note capture
- Action list and dated activity timeline
- Music recommendations and YouTube playback flow
- Trip planning with current sources and travel shortcuts
- Weather lookup
- Spreadsheet creation
- Multilingual speech recognition
- Local history controls
